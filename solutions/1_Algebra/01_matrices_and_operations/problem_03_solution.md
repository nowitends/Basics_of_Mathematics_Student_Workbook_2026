# Exercise 3

We compare the inner dimensions.

- $AB$: yes, result $2\times4$.
- $BA$: no ($4\neq2$).
- $BC$: yes, result $3\times2$.
- $CB$: no.
- $AC$: no.
- $CA$: yes, result $4\times3$.
- $AD$: no.
- $DA$: yes, result $2\times3$.

The rule is: number of columns of first matix = number of rows of second one.
