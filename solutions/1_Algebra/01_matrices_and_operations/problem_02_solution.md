# Exercise 2

$$A+B=\begin{pmatrix}5&0\\-1&8\end{pmatrix}$$

$$A-B=\begin{pmatrix}-3&4\\-1&-2\end{pmatrix}$$

and
$$3A-2B
=\begin{pmatrix}3&6\\-3&9\end{pmatrix}
-\begin{pmatrix}8&-4\\0&10\end{pmatrix}
=\begin{pmatrix}-5&10\\-3&-1\end{pmatrix}.$$

Addition works only if the matrices have the same dimensions, because entries are added in corresponding places.
