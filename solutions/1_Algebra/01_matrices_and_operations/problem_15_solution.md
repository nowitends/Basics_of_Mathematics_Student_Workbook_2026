# Exercise 15

First:
$$AB=\begin{pmatrix}5&2\\1&4\end{pmatrix}$$
so
$$(AB)C=
\begin{pmatrix}10&3\\2&-3\end{pmatrix}.$$

Now
$$BC=
\begin{pmatrix}2&1\\4&1\\-2&-4\end{pmatrix}$$
and
$$A(BC)=
\begin{pmatrix}10&3\\2&-3\end{pmatrix}.$$

same answer, as expected from associativity.

Calculating $AB$ first is a little shorter here because the intermediate matrix is only $2\times2$.
